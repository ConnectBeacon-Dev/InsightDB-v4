Try asking questions like:

  • List companies in Pune

📝 How to Use

  • api-url: URL to your chatbot API (default: http://127.0.0.1:8000)
  • theme: Primary color for the header (default: #6915CF)
  • height: Widget height (default: 600px)

Implementation Code

<!-- Include the web component script --> <script src="chatbot-widget.js"></script> <!-- Use the custom element --> <chatbot-widget api-url="http://127.0.0.1:8000" theme="#6915CF" height="500px" ></chatbot-widget>
