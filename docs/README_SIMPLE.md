## ⚙️ Configuration

All configuration in `.env.production`:

```env
SSO_SHARED_SECRET=<auto-generated>
CHATBOT_URL=https://chat.connectbeacon.com/aichat/sso
LOGIN_URL=https://login.connectbeacon.com
PORT=8000
LOGIN_PORT=5000
```

**Important:** 
- `.env.production` is auto-generated on first run
- It's gitignored for security
- Back it up securely

## 🔐 Security

- Secrets stored in `.env.production` (gitignored)
- JWT tokens for SSO authentication
- HTTPS via nginx (SSL certificates required)
- Secure session cookies

## 📊 Architecture

```
User Browser
    ↓
Nginx (HTTPS :443)
    ↓
├─ login.connectbeacon.com → Python Login Server (:5000)
└─ chat.connectbeacon.com  → Python Chatbot Server (:8000)
```

## 🐛 Troubleshooting

### JWT Errors
- Ensure `SSO_SHARED_SECRET` matches in both chatbot and your backend
- Restart servers after changing secret

### Can't Access URLs
- Check nginx is running
- Verify DNS points to correct IP
- Check firewall allows ports 443, 8000, 5000

### Servers Won't Start
- Check logs in `logs/` directory
- Ensure virtual environment exists: `.venv/`
- Verify ports 8000 and 5000 are free
